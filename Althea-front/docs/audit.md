## 3. Bilan des tests

### Navigation au clavier

La navigation avec les touches Tab et Maj + Tab
fonctionne correctement sur les deux pages.

Les éléments interactifs sont accessibles
au clavier et le focus est visible.

Le champ de quantité et le bouton d'achat
désactivés sont ignorés par la navigation.

### Zoom à 200 %

Les deux pages ont été testées avec un zoom
de 200 %.

Aucun élément important coupé ou caché
n'a été constaté lors des tests.

### Lecteur d'écran

Les tests réalisés avec le Narrateur Windows
n'ont pas révélé de problème particulier.

Les différents éléments sont annoncés
correctement lors de la navigation.

### Lighthouse

Les deux pages obtiennent un score
d'accessibilité de 96/100.

L'objectif minimum de 90/100 demandé
dans le TP est donc atteint.

Les détails des audits Lighthouse restent
à consulter pour identifier les éventuelles
corrections supplémentaires.

## 4. Conclusion

Les tests manuels n'ont pas révélé de problème
majeur d'accessibilité.

Les deux pages dépassent le score minimum
demandé par le TP.

Le rapport devra être complété avec les
éventuelles anomalies signalées par Lighthouse
et les résultats de leurs nouveaux tests.
